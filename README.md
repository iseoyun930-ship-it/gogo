# ST Phone — 폰·SNS 시뮬레이터 (SillyTavern 확장)

화면에 떠 있는 📱 버블을 누르면 폰이 열려요. 캐릭터와 문자를 주고받고, SNS를 보고, 생리 주기·임신·일정·날씨·뉴스까지 관리할 수 있는 실리태번 확장이에요.
코드가 앱 구조·저장·정보 차단을 맡고, AI는 **내용(문자·게시글·댓글·뉴스)만** 만들어요.

## 앱 (홈 화면 9개)

| 앱 | 하는 일 |
|---|---|
| 캐릭터 | 프로필(소개·생일·메모), 팔로우 설정, 문자 보내기 |
| 메시지 | 캐릭터별 대화방, 입력 중 표시, 먼저 연락 오게 하기, 자동 답장 |
| SNS | AI 게시글 새로고침, 글쓰기, 좋아요, 댓글, AI 반응 생성 |
| Luna | 생리 주기 추적: 현재 단계, 다음 예정일, 배란 예정일, 기록 관리 |
| 임신 | 주차·출산 예정일·진행률·크기 비유·메모 |
| 캘린더 | 월간 달력, 일정 추가, 생일·생리·출산 예정일 자동 표시 |
| 월드 | AI가 만드는 날씨와 뉴스, 세계관 설정 메모 |
| 계정 등록 | NPC 계정 추가 (이름·소개·생일) |
| 설정 | 폰 시간, 자동 모드, 메인 채팅 연동, 테마·글자 크기 |

## 특징

- **정보 차단**: 캐릭터는 자신이 보내거나 올린 것, 팔로우한 계정의 글만 알아요.
- **트래커 공개 범위**: Luna·임신 기록은 추적을 켠 계정만 메인 채팅에 전달되고, "모든 캐릭터에게 공유"를 켜기 전에는 본인만 알아요.
- **자동 모드**: 메인 채팅이 진행되면 캐릭터가 알아서 글을 올리고, 먼저 문자를 보내고, 댓글을 달아요. (기본 꺼짐)
- **시간 연동**: 폰 시간(새벽·아침·밤 등)과 요일, 날씨, 일정이 문자·글 생성에 반영돼요.
- **채팅별 저장**: RP마다 폰 데이터가 따로 저장돼요.
- **보기 편한 화면**: 큰 글씨 옵션, 4가지 테마, 포인트 색 변경, 모바일 전체 화면.

## 설치

1. 실리태번 → **Extensions(퍼즐 아이콘)** → **Install extension**
2. `https://github.com/내아이디/st-phone` 를 붙여 넣고 설치
3. 페이지를 새로고침하면 📱 버블이 나타나요. (끌어서 위치 이동)

## GitHub에 올리는 방법 (웹)

1. github.com → **New repository** → 이름 `st-phone`, **Public**
2. **Add file → Upload files** 로 `manifest.json`, `index.js`, `style.css`, `README.md` 를 **저장소 맨 위(루트)** 에 올리기
3. **Commit changes**
4. `manifest.json` 의 `YOUR_NAME`, `YOUR_GITHUB_ID` 를 내 정보로 바꾸기

수정 후에는 같은 방법으로 다시 올리고 실리태번 Extensions에서 업데이트하면 돼요.

## 사용 팁

- 먼저 **캐릭터 채팅**을 열어야 폰이 동작해요.
- SNS 새로고침, 월드 새로고침, 문자 답장은 AI 호출이 1번씩 들어가요.
- AI 응답은 JSON으로 받아요. 가끔 해석에 실패하면 다시 눌러 주세요.
- 설정에서 **메인 채팅 연동**을 끄면 메인 채팅은 폰 내용을 몰라요.
- Luna·임신은 **계정을 고른 뒤 추적 시작**을 눌러야 켜져요. 켜지 않은 계정은 어디에도 반영되지 않아요.

## 자동 모드

설정 → **자동 모드**에서 켜요.
- **캐릭터 메시지 N개마다 실행**: 기본 4개마다 AI 호출 1번
- **메시지 1개당 폰 시간(분)**: 메인 채팅이 진행될수록 폰 시간도 흘러요 (0이면 안 흘러감)
- **지금 한 번 실행**: 바로 테스트

## 요구 사항

- SillyTavern 1.12 이상 (`generateQuietPrompt`, `setExtensionPrompt`, `chatMetadata` 사용)
